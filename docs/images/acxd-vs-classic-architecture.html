AICC Builder 3.0 · runtime targets

One interview, two ways to run the agent

The interview, the review and the six-asset bundle are the same. The Classic target puts a Lex bot and an Amazon Connect AI agent in front of MCP tools served by AgentCore Gateway; the ACXD target hands the caller to an Agentic CX Designer application whose data requests call the generated API directly.

Entry point

Classic: the Contact Flow's Lex block sends the utterance to a Lex bot that hands over to the AI agent. ACXD: the Agentic CX block hands the whole conversation to the application; its Default, Escalation, Error and idle-timeout branches come back into the flow.

Reasoning

Classic: an AI Prompt drives a Q in Connect AI agent. ACXD: deterministic flows the interview approved — Welcome, operation flows, FollowUp, RequestAgent, Escalation — plus slot types, guardrails and a knowledge base.

Tools

Classic: the OpenAPI spec becomes MCP tools on AgentCore Gateway, called with a JWT. ACXD: each operation is a Data Request that POSTs the collected slots to API Gateway with the API key held as an ACXD secret. The Lambda handlers and tables behind the API are the same bundle in both.
