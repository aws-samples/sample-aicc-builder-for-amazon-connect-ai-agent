AICC Builder 3.0 · validation pipeline

Which checks join which assets

Every edge is a deterministic check that reads both endpoints. Grey edges are the Classic checks in validate_parameter_consistency and review_gates; orange edges are the ACXD D9 checks; the response-contract projection is the one gate that rewrites an asset (OpenAPI) from the spec.

Classic ids

D1 spec ↔ Lambda ↔ OpenAPI field names, primary keys, GSI union (D1-1), table env vars (D1-2), data wrapper (D1-3), asset counts (D1-4), tool fields (D1-5) · D2 IAM actions derived from SDK calls vs the CloudFormation roles · D3 RDS Data API contract · D4 SQL identifiers, casts, NOT NULL columns, bind types vs the scanned schema · D5 Connect invoke permission for every Lambda the flow calls · D6 flow session attributes named in the prompt, D6b prompt variable re-lint · D7 UpdateQSession env · D8 success status code · SAMPLE_DATA customer rows present in the template · PARITY spec ↔ OpenAPI shapes and enums.

ACXD ids

D9-2 flow determinism vs the confirmed plan · D9-4 slot enum/regex/length vs the FieldSpec · D9-3 Data Request path /tools/<op> and request/response field sets vs OpenAPI · D9-8 ApiKeyRequired on every method and an x-api-key Secret header (folds D2–D5 as blocking) · D9-6 Agentic CX block, acxdBinding, four branches, context variables, no pre-block $.AgenticCX read · D9-5 planned knowledge base → articles with a question and an answer · D9-1/D9-7 (not drawn) structure, uniqueness, runtime contract, identity and ASCII metadata inside the application itself.

Spec is the hub

The OperationSpec is read by every Classic check and by D9-2/D9-4, so a wrong FieldSpec surfaces as findings on several assets at once: fix the spec, then regenerate, rather than patching each asset. Lambda ↔ CloudFormation is the widest seam (six check families) and runs only when the merged template is found. Two gates write: the response-contract projection re-derives the OpenAPI schemas from the spec, and the Lambda adapter is injected into the handlers at ACXD packaging.
